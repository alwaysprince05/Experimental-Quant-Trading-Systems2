## Dev/Creator = alwaysprince05

This repository contains five experimental quant trading systems built using Python, statistical modeling, machine learning concepts, and synthetic market data.

The goal of these projects is to explore quantitative finance concepts through simulation, visualization, and research-focused experimentation.

These projects are not intended for live trading or financial advice.

---

# 1. Statistical Arbitrage Bot

## Overview

Research system for studying pricing inefficiencies between correlated assets and identifying temporary market dislocations.

## Features

* Synthetic asset generation
* Pair relationship analysis
* Spread calculation
* Z-score modeling
* Signal generation
* Backtesting simulation
* Performance visualization

## Relevant Concepts

* Statistical Arbitrage
* Pairs Trading
* Cointegration
* Z-Score

Wikipedia:

https://en.wikipedia.org/wiki/Statistical_arbitrage

# How To Fork

1. Open the repository on GitHub.
2. Click the Fork button.
3. Clone your fork locally:

```bash
git clone https://github.com/your-username/Experimental-Quant-Trading-Systems.git
```

4. Enter the project directory:

```bash
cd Experimental-Quant-Trading-Systems
```

5. Run any project using its main.py file.
